# HealthConnect — Healthcare Services Platform & Documentation Hub

**HealthConnect** is a responsive healthcare services web application and project documentation portal built with beginner-friendly **HTML5, CSS3, and Vanilla JavaScript**.

## Features Included

### Interactive Platform (`index.html`)
- **Healthcare Service Suggestions**: Select a health goal or symptom category to receive tailored care recommendations and specialist matches.
- **Find a Doctor**: Search by doctor name or condition, filter by specialty, and jump directly to booking.
- **Hospital & Clinic Directory**: Browse local hospitals, urgent care clinics, and diagnostic centers by facility type or location.
- **Healthcare Information**: Read curated wellness and preventive care guides in an accessible modal reader.
- **Appointment Booking Demo**: Book simulated appointments with date/time slot selection, form validation, confirmation cards, and `localStorage` persistence.

### Project Documentation Pages (`pages/`)
1. **Project Brief** (`pages/project-brief.html`)
2. **Product Requirement Document (PRD)** (`pages/prd.html`)
3. **Tech Stack – Languages & Technologies** (`pages/tech-stack.html`)
4. **Design References – Dribbble, Pinterest & Behance** (`pages/design-references.html`)
5. **Implementation Plan** (`pages/implementation-plan.html`)

## How to Run
1. **Simplest way:** Double-click `index.html` to open it directly in your browser.
2. **With a local server (optional):**
   - Python: `python -m http.server 8080`
   - Node.js: `npx serve .`
   - VS Code: Use the **Live Server** extension.
